# KiraKira Daily 配布用リポジトリ

6歳児向け習慣化アプリ「KiraKira Daily（キラキラデイリー）」の配布用リポジトリです。
オフラインで動作するAndroidアプリで、Google PlayやApp Storeを経由せず、こちらから直接インストール・更新できます。

## インストール方法

1. [Releases](../../releases/latest) から最新版の `app-release.apk` をダウンロード
2. ダウンロードしたファイルをタップして開く
3. 「提供元不明のアプリ」の警告が出た場合は、案内に従って許可（初回のみ）
4. インストール完了後、アプリを起動

## 既存端末の更新について

すでにアプリが入っている端末の場合、同じ手順で新しいバージョンをインストールすると、上書き更新されます（アンインストール不要）。通常はアプリ内のデータ（進捗・キャラクターの状態など）はそのまま引き継がれます。

念のため、大きな更新の前は保護者設定内の「データのひきつぎ」機能でバックアップを取っておくことをおすすめします。
